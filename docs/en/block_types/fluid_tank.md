# Fluid Tank

**Requires [Tinkers' Construct 3](https://github.com/SlimeKnights/TinkersConstruct)**

Path: `things/<namespace>/block/`

**(Object)** Root object.
- **type** ([Resource Location](https://minecraft.wiki/w/Identifier)) Block type ID, must be `"jsonmore:fluid_tank"`
- **capacity** (integer) Tank capacity. Default `4000`.
- **item** (object)
  - **type** ([Resource Location](https://minecraft.wiki/w/Identifier)) Item type ID, must be `"jsonmore:fluid_tank"`
  - Other properties supported by [Item Definition](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)
- Other properties supported by [Block Definition](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)
