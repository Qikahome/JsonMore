# Sign (Block)

Path: `things/<namespace>/block/`

**(Object)** Root object.
- **type** ([Resource Location](https://minecraft.wiki/w/Identifier)) Block type ID, must be `"jsonmore:standing_sign"` or `"jsonmore:wall_sign"`
- **wood_type** (wood type) Optional, default `"oak"`
- **item** (object) Leave blank; register the item separately via [Standing and Wall Item](../item_types/standing_and_wall.md)
- Other properties supported by [Block Definition](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)
