# 材料属性类型（Dynamic Material Stat Type）

**需要安装 [匠魂 3](https://github.com/SlimeKnights/TinkersConstruct)**

路径：`things/<命名空间>/material_stat_type/`

## 基本格式

```json
{
    "type": "jsonmore:plain",
    "durability_field": "durability",
    "stats": [
        {
            "type": "tconstruct:float",
            "name": "durability",
            "stat": "durability",
            "default_value": 100.0,
            "operation": "update",
            "description": "stat.jsonmore.durability.desc",
            "tooltip": "stat.jsonmore.durability.tooltip"
        },
        {
            "type": "tconstruct:tier",
            "name": "harvest_tier",
            "stat": "harvest_tier",
            "default_value": "diamond",
            "description": "stat.jsonmore.harvest_tier.desc"
        }
    ]
}
```

## 字段说明

### 顶层字段

- **`type`**（资源路径，必需）
  - 材料属性类型的类型 ID
  - 必须为`"jsonmore:plain"`

 - **`durability_field`**（字符串，可选）
  - 指定用于修复的耐久度字段名称
  - 如果设置，使用该属性类型的工具部件可以被修复
  - 默认为空字符串（不可修复）

- **`stats`**（数组，必需）
  - 动态属性字段列表
  - 可以是空数组 `[]`

### 每个 stat 字段的格式

**通用字段：**

- **`type`**（资源路径，必需）
  - 属性字段类型
  - 可选项：
    - `"tconstruct:float"` - 浮点数值属性
    - `"tconstruct:tier"` - 挖掘等级属性

- **`name`**（字符串，必需）
  - 属性字段的名称
  - 用于 JSON 序列化/反序列化时的键名

- **`stat`**（资源路径，必需）
  - ToolStat 的 ID
  - 如果未指定命名空间，自动添加 `tconstruct:` 前缀
  - 示例：`"durability"`、`"tconstruct:attack_damage"`、`"harvest_tier"`

- **`description`**（字符串，可选）
  - 属性描述的翻译键
  - 默认为空字符串（使用 ToolStat 的默认描述）

- **`tooltip`**（字符串，可选）
  - 工具提示的翻译键
  - 默认为空字符串（使用默认格式）

**Float 类型特有字段：**

- **`default_value`**（浮点数，必需）
  - 属性的默认值
  - 示例：`100.0`、`1.5`、`-0.5`

- **`operation`**（字符串，必需）
  - 应用于工具时的计算方式
  - 可选项：
    - `"update"` - 直接更新值（默认）
    - `"add"` - 加法
    - `"percent"` - 百分比加成
    - `"multiply"` - 乘法
    - `"multiply_all"` - 全局乘法

**Tier 类型特有字段：**

- **`default_value`**（字符串，必需）
  - 挖掘等级的默认值
  - 可选项：`"wood"`、`"stone"`、`"iron"`、`"diamond"`、`"gold"`、`"netherite"`
  - 可以不带命名空间（自动添加 `minecraft:`）

## 示例

### 示例 1：标准的可修复属性类型

```json
{
    "durability_field": "durability",
    "stats": [
        {
            "type": "tconstruct:float",
            "name": "durability",
            "stat": "durability",
            "default_value": 100.0,
            "operation": "update"
        },
        {
            "type": "tconstruct:float",
            "name": "attack_damage",
            "stat": "attack_damage",
            "default_value": 1.0,
            "operation": "add",
            "description": "stat.mymod.attack_damage.desc",
            "tooltip": "stat.mymod.attack_damage.tooltip"
        },
        {
            "type": "tconstruct:float",
            "name": "mining_speed",
            "stat": "mining_speed",
            "default_value": 2.0,
            "operation": "multiply"
        },
        {
            "type": "tconstruct:tier",
            "name": "harvest_tier",
            "stat": "harvest_tier",
            "default_value": "iron",
            "description": "stat.mymod.harvest_tier.desc"
        }
    ]
}
```

### 示例 2：不可修复的特殊属性类型

```json
{
    "stats": [
        {
            "type": "tconstruct:float",
            "name": "special_power",
            "stat": "mymod:special_power",
            "default_value": 50.0,
            "operation": "add",
            "description": "stat.mymod.special_power.desc"
        }
    ]
}
```

### 示例 3：空的属性类型

```json
{
    "stats": []
}
```

### 示例 4：使用百分比和乘法的属性类型

```json
{
    "durability_field": "durability",
    "stats": [
        {
            "type": "tconstruct:float",
            "name": "durability",
            "stat": "durability",
            "default_value": 200.0,
            "operation": "update"
        },
        {
            "type": "tconstruct:float",
            "name": "attack_damage",
            "stat": "attack_damage",
            "default_value": 0.2,
            "operation": "percent",
            "tooltip": "stat.mymod.attack_damage.percent"
        },
        {
            "type": "tconstruct:float",
            "name": "mining_speed",
            "stat": "mining_speed",
            "default_value": 1.5,
            "operation": "multiply"
        }
    ]
}
```

## 注意事项

1. **`id` 字段不需要** - 系统会从文件名自动生成
2. **`stat` 字段会自动添加命名空间** - 如果未指定，默认添加 `tconstruct:`
3. **`default_value` 的格式** - Tier 类型可以直接写等级名称（如 `"diamond"`），无需 `minecraft:` 前缀
4. **`durability_field` 必须与某个 stat 的 `name` 匹配** - 这样才能正确获取修复值
5. **`operation` 仅 Float 类型需要** - Tier 类型固定使用 `update` 操作
6. **空的 stats 数组是合法的** - 但不推荐，因为没有实际效果
