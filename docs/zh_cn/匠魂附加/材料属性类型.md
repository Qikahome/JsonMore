# 材料属性类型

 **需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**

路径：`things/<domain>/material_stat_type/`

样例：
```json
{
    "parent": "jsonmore:none",
    "type": "jsonmore:plain",
    "can_repair": true,
    "stats": {
        "tconstruct:durability": {
            "type": "float",
            "value": 1.0,
            "operator": "update",
            "infoToolTip":"",
            "descToolTip":""
        }
    }
}
```
### `"parent"`
资源路径。可选。
另一个json注册的`material_stat_type`的资源路径。

### `"type"`
资源路径。必填。
`material_stat_type`的类型
可选项：`"jsonmore:plain"`

### `"can_repair"`
布尔。可选。默认为`false`
含有该种材料属性类型的部件的工具是否可以使用该部件对应的材料修复。

### `"stats`
字典[资源路径:字典]。可选。
该种材料属性类型的部件所含有的属性。
对于每一个键，必须为已注册的ToolStatID的完全限定资源路径。
对于每一组值：
- **`"type"`** 必填。参数类型。可以为`"float"`或`"tier"`。
- **`"value"`** 必填。该参数默认值。当`"type"`为`"float"`时，任意浮点数；当`"type"`为`"tier"`时，可填`"wood"`,`"stone"`,`"iron"`,`"diamond"`,`"gold"`,`"netherite"`。
- **`"operator"`** 当`"type"`为`"float"`时必填。应用于工具时的计算方式。可以为`"update"`,`"add"`,`"percent"`,`"multiply"`,`"multipy_all"`。
- **`"infoToolTip"`** 可选。当`"operator"`为`"percent"`时的翻译键。默认为`"tool_stat.<命名空间>.<文件名>.<ToolStatID>"`
- **`"descToolTip"`** 可选。参数属性翻译键。默认为`"<文件名>.<命名空间>.<ToolStatID>.description"`
