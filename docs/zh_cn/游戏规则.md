# 游戏规则（GameRule）

路径：`things/<命名空间>/gamerule/`

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）GameRule 类型，必须是以下之一：
  - `jsonmore:boolean` - 布尔值类型（true/false）
  - `jsonmore:integer` - 整数值类型
- **default_value**（布尔值 或 整数）GameRule 的默认值，类型必须与 `type` 匹配
- **category**（字符串）GameRule 的分类，决定它在"创建世界"屏幕中的分组，可选值见下表，默认 `misc`

| 分类值 | 说明 |
|--------|------|
| `chat` | 聊天相关设置 |
| `cheats` | 作弊相关设置 |
| `drops` | 掉落相关设置 |
| `mobs` | 生物相关设置 |
| `misc` | 其他杂项设置 |
| `player` | 玩家相关设置 |
| `spawning` | 生成相关设置 |
| `updates` | 更新相关设置 |

## 使用方式

使用 `/gamerule` 命令查看或修改 GameRule：

```bash
# 查看当前值
/gamerule <命名空间>.<规则名>

# 修改为指定值
/gamerule testpack.test_boolean_rule true
/gamerule testpack.test_integer_rule 50
```

## 示例

### 布尔类型 GameRule
```json
{
  "type": "jsonmore:boolean",
  "default_value": true,
  "category": "misc"
}
```

### 整数类型 GameRule
```json
{
  "type": "jsonmore:integer",
  "default_value": 10,
  "category": "misc"
}
```

## 配方条件

`jsonmore:gamerule` 可用作配方加载条件，根据游戏规则的当前值决定配方是否加载。

**（Object）** 根对象。
- **rule**（字符串）游戏规则名，点号格式（与 `/gamerule` 命令一致）
- **value**（可选）期望值：
  - 不存在 → 视为**布尔规则**，检查是否为 `true`
  - 整数（如 `5`）→ 视为**整数规则**，精确匹配
  - 区间字符串（如 `[1,3]`、`[2,)`）→ 视为**整数规则**，区间匹配

> 布尔规则的取反请配合 `forge:not` 实现，无需在 `jsonmore:gamerule` 中显式指定 `false`。

```jsonc
// 布尔规则：规则值为 true 时加载配方
{
  "type": "jsonmore:gamerule",
  "rule": "jsonmore.some_flag"
}

// 布尔规则取反：配合 forge:not
{
  "type": "forge:not",
  "value": {
    "type": "jsonmore:gamerule",
    "rule": "jsonmore.some_flag"
  }
}

// 整数规则：精确匹配
{
  "type": "jsonmore:gamerule",
  "rule": "jsonmore.some_count",
  "value": 5
}

// 整数规则：区间匹配（闭区间）
{
  "type": "jsonmore:gamerule",
  "rule": "jsonmore.some_count",
  "value": "[3,10)"
}

// 整数规则：区间匹配（仅下界）
{
  "type": "jsonmore:gamerule",
  "rule": "jsonmore.some_count",
  "value": "[100,]"
}
```

### 完整示例

仅当 `jsonmore.enable_advanced_crafting` 为 `true` 时，才加载高级合成配方：

```json
{
  "type": "minecraft:crafting_shaped",
  "conditions": [
    {
      "type": "jsonmore:gamerule",
      "rule": "jsonmore.enable_advanced_crafting"
    }
  ],
  "pattern": ["###", "#X#", "###"],
  "key": {
    "#": { "item": "minecraft:diamond" },
    "X": { "item": "minecraft:nether_star" }
  },
  "result": { "item": "minecraft:beacon" }
}
```
