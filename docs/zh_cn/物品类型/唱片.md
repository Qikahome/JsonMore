# 唱片

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:record"`
- **sound**（声音事件ID）唱片播放的声音事件，必填
- **length**（整数，单位：游戏刻）唱片播放时长，必填。注意不是秒（原版唱片的定义以秒计，此处需自行 ×20）
- **comparator_value**（整数，默认`15`）唱片在唱片机中播放时比较器输出的红石信号强度
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项

该物品还需加入 `minecraft:music_discs` 物品标签才能放入唱片机（可在数据包内以标签追加的方式加入）。

## 示例

```json
{
  "type": "jsonmore:record",
  "sound": "minecraft:music_disc.cat",
  "length": 3700,
  "comparator_value": 15,
  "max_stack_size": 1
}
```

该示例注册了一张播放时长与原版"猫"唱片一致的唱片（`185` 秒 × `20` 刻）。`sound` 指定的声音事件必须已注册，否则物品解析时会报错。
