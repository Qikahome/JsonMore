# 唱片

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:record"`
- **jukebox_song**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）指向的唱片歌曲，格式为 `<命名空间>:<路径>`，对应数据包中的 `data/<命名空间>/jukebox_song/<路径>.json`，必填
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项

**1.21 起唱片改为数据驱动**，不再有 1.20.1 的 `sound` / `length` / `comparator_value` 三件套——这些信息全部定义在 `jukebox_song` 指向的歌曲文件里。物品本身固定为单堆叠（`max_stack_size: 1`），并会自动带上 `jukebox_playable` 数据组件，因此**不再需要**加入 `minecraft:music_discs` 物品标签即可放入唱片机。

## 歌曲定义

必须自行在数据包中提供歌曲文件 `data/<命名空间>/jukebox_song/<路径>.json`，字段如下：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `sound_event` | 声音事件ID | 是 | 播放的声音事件 |
| `description` | 文本组件 | 是 | 唱片在提示信息中显示的名称 |
| `length_in_seconds` | 正浮点数 | 是 | 播放时长，单位：秒 |
| `comparator_output` | 整数 | 是 | 唱片机播放时比较器输出的红石信号强度，取值 `0`~`15` |

## 示例

```json
{
  "type": "jsonmore:record",
  "jukebox_song": "testpack:test_record"
}
```

配套的歌曲定义 `data/testpack/jukebox_song/test_record.json`：

```json
{
  "sound_event": "minecraft:music_disc.cat",
  "description": { "translate": "jukebox_song.testpack.test_record" },
  "length_in_seconds": 185.0,
  "comparator_output": 2
}
```

该示例注册了一张与"猫"唱片同音效、同 185 秒时长的唱片。
