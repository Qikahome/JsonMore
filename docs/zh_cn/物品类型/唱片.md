# 唱片

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:record"`
- **jukebox_song**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）唱片引用的歌曲，必填。指向数据包里的 `data/<命名空间>/jukebox_song/<路径>.json`
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项

## 数据包中的歌曲定义

唱片物品本身只是一条引用，真正的播放信息由数据包里的歌曲定义提供（路径 `data/<命名空间>/jukebox_song/<路径>.json`）：

**（Object）** 根对象。
- **sound_event**（声音事件ID）唱片播放的声音事件，必填
- **description**（[文本组件](https://zh.minecraft.wiki/w/%E6%96%87%E6%9C%AC%E7%BB%84%E4%BB%B6)）唱片在唱片机中播放时显示的名称，必填
- **length_in_seconds**（浮点数）播放时长，单位为秒，必填，必须为正数
- **comparator_output**（整数，`0`–`15`）唱片在唱片机中播放时比较器输出的红石信号强度，必填

> **注意**：1.21 起唱片完全数据驱动，1.20.1 的 `sound` / `length` / `comparator_value` 三件套已不存在；唱片也不再需要加入 `minecraft:music_discs` 物品标签才能放入唱片机，能否插入完全由 `jukebox_playable` 组件决定。

## 示例

物品定义 `things/testpack/item/test_record.json`：

```json
{
  "type": "jsonmore:record",
  "jukebox_song": "testpack:test_record",
  "max_stack_size": 1
}
```

对应的歌曲定义 `data/testpack/jukebox_song/test_record.json`：

```json
{
  "comparator_output": 15,
  "description": {
    "translate": "jukebox_song.testpack.test_record"
  },
  "length_in_seconds": 185.0,
  "sound_event": "minecraft:music_disc.cat"
}
```

该示例注册了一张播放时长与原版"猫"唱片一致（`185` 秒）的唱片。`jukebox_song` 指向的歌曲必须存在于数据包中，否则在构建物品栈、解析 `jukebox_playable` 组件时会报错；`sound_event` 指定的声音事件必须已注册。`description` 是显示用的文本组件，通常写成 `jukebox_song.<命名空间>.<路径>` 的翻译键并在语言文件中提供。
