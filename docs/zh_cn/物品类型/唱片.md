# 唱片

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:record"`
- **jukebox_song**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）唱片播放的曲目，必填，指向数据包中的 `data/<命名空间>/jukebox_song/<路径>.json`
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项

1.21 起唱片改为数据驱动：唱片物品自身不再保存音效、时长与比较器输出，这些都写在 `jukebox_song` 指向的曲目条目里。注册时物品会被自动挂上 `jukebox_playable` 组件（以 key 形式引用曲目，因此不要求曲目在物品注册前就已加载），堆叠上限固定为 `1`。

该物品**无需**加入 `minecraft:music_discs` 物品标签：1.21 起唱片机直接识别 `jukebox_playable` 组件，原版已不再使用该标签。

## 曲目条目

路径：`data/<命名空间>/jukebox_song/<路径>.json`

**（Object）** 根对象。
- **sound_event**（声音事件ID）唱片播放的音效，必填
- **description**（文本组件）曲目的描述，必填，展示在唱片机的提示与物品提示中
- **length_in_seconds**（浮点数，单位：秒）唱片播放时长，必填
- **comparator_output**（整数）唱片在唱片机中播放时比较器输出的红石信号强度，必填

## 示例

物品：

```json
{
  "type": "jsonmore:record",
  "jukebox_song": "testpack:test_record"
}
```

曲目：

```json
{
  "sound_event": "minecraft:music_disc.cat",
  "description": {
    "translate": "jukebox_song.testpack.test_record"
  },
  "length_in_seconds": 185,
  "comparator_output": 15
}
```

该示例注册了一张与原版"猫"唱片同音效、时长 `185` 秒的唱片。`sound_event` 指定的声音事件必须已注册，否则物品解析时会报错；`description` 用到的翻译键需在语言文件中提供，否则会直接显示键名。`jukebox_song` 指向的曲目条目必须存在于数据包中，否则播放时无法解析。
