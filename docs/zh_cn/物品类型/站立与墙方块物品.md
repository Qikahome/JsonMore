# 站立与墙方块物品

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:standing_and_wall"`
- **block**（方块ID）站立方块，放置在地面或天花板上，必填
- **wall_block**（方块ID）墙方块，放置在侧面上，必填
- **use_block_name**（布尔，默认`true`）是否使用方块名作为物品显示名
- **direction**（字符串，默认`"down"`）站立方块的附着方向，可选值：`down`、`up`、`north`、`south`、`west`、`east`
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项
