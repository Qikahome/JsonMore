# 告示牌

路径：`things/<命名空间>/item/`

格式如下：

 **（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:sign"`
- **standing_sign**（[告示牌方块](../%E6%96%B9%E5%9D%97%E7%B1%BB%E5%9E%8B/%E5%91%8A%E7%A4%BA%E7%89%8C.md)）方块ID,必填
- **wall_sign**（告示牌方块）同上
- 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项
