# 地幔指南书

**需要安装 [Mantle](https://github.com/SlimeKnights/Mantle)**

路径：`things/<命名空间>/item/`

格式如下：

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型 ID，必须是 `"jsonmore:book"`。
- **book_id**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）书籍的唯一标识符，格式 `<命名空间>:<书籍名称>`。
- **book_data**（[JSON 数组](https://zh.minecraft.wiki/w/JSON)）书籍数据变换器列表，每个元素可以是：
  - **字符串**：变换器 ID，如 `"mantle:index"`。
  - **对象**：带参数的变换器，必须包含 `"type"` 字段，如 `{"type": "mantle:repository", "id": "..."}`。
- 其他在 [物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md) 中支持的项。

## 可用的变换器

### Mantle 内置变换器

- **mantle:index** – 添加书的索引页面。
- **mantle:padding** – 在书籍末尾添加空白填充页，确保总页数为偶数，保证双页布局不错位。
- **mantle:content_table** – 添加目录页面。
- **mantle:repository** – 添加书籍内容仓库。需要参数：
  - **id**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）书籍内容的路径，格式 `<命名空间>:book/<书籍名称>`，对应资源目录 `assets/<命名空间>/book/<书籍名称>/`。
- **mantle:set_unicode** – 设置 Unicode 字体渲染器，支持非 ASCII 字符（如中文、日文等）。

### 匠魂变换器

- **tconstruct:tool_tag_injector** – 添加工具标签注入器（从标签自动生成工具条目）。
- **tconstruct:modifier_tag_injector** – 添加修饰剂标签注入器（从标签自动生成强化条目）。
- **tconstruct:tool_section** – 添加工具章节。可选参数：
  - **tool_type**（字符串）工具类型，如 `"melee"`、`"ranged"`、`"armor"` 等, 默认为 `"tools"`。
  - **large_title**（布尔值）是否使用大标题，默认为 `false`。
  - **center_title**（布尔值）是否居中标题，默认为 `false`。
- **tconstruct:modifier_section** – 添加修饰剂章节。可选参数：
  - **modifier_type**（字符串）修饰剂类型，如 `"upgrades"`、`"defense"`、`"slotless"` 等, 默认为 `"modifiers"`。
  - **large_title**（布尔值）是否使用大标题，默认为 `false`。
  - **center_title**（布尔值）是否居中标题，默认为 `false`。
- **tconstruct:tier_range_material_section** – 添加按挖掘等级分组的材料章节。
- **tconstruct:fluid_effect_injector** – 添加流体效果注入器（为流体条目添加效果说明）。

## 示例

### 示例 1：基础指南书（仅 Mantle）

```json
{
    "type": "jsonmore:book",
    "book_id": "mymod:guide_book",
    "book_data": [
        "mantle:index",
        "mantle:padding",
        "mantle:content_table",
        {
            "type": "mantle:repository",
            "id": "mymod:book/guide_book"
        }
    ]
}
```

### 示例 2：匠魂工具指南书

```json
{
    "type": "jsonmore:book",
    "book_id": "mymod:tinkers_guide",
    "book_data": [
        "mantle:index",
        "mantle:padding",
        "mantle:content_table",
        {
            "type": "mantle:repository",
            "id": "mymod:book/tinkers_guide"
        },
        "tconstruct:tool_tag_injector",
        "tconstruct:modifier_tag_injector",
        {
            "type": "tconstruct:tool_section",
            "tool_type": "melee",
            "large_title": true
        },
        {
            "type": "tconstruct:modifier_section",
            "modifier_type": "armor"
        },
        "tconstruct:tier_range_material_section",
        "tconstruct:fluid_effect_injector",
        "mantle:set_unicode"
    ],
    "creative_tab": "mymod:main",
    "rarity": "uncommon"
}
```

## 注意事项

1. **`book_id` vs `repository.id`**  
   - `book_id` 是书籍的物品 ID（如 `mymod:guide_book`）。  
   - `repository.id` 是书籍内容的路径（如 `mymod:book/guide_book`），对应资源目录 `assets/mymod/book/guide_book/`。

2. **Unicode 支持**  
   如果需要显示中文、日文等非 ASCII 字符，必须添加 `mantle:set_unicode` 变换器。

3. **书籍内容**  
   需要在资源包中提供书籍内容，<del>详见 [Mantle 文档](https://github.com/SlimeKnights/Mantle)</del>我也不知道哪里有文档。

4. **变换器顺序**  
   动态内容生成器（如 `tconstruct:tool_tag_injector`）应当放在 `mantle:index` 之前，以确保索引页包含它们生成的页面。`mantle:padding` 通常放在最后。
