# 放置方向（Placing Directions）

放置方向用于控制方块放置时的朝向。

| 方向值 | 说明 |
|--------|------|
| `up` | 始终朝上 |
| `down` | 始终朝下 |
| `north` | 始终朝北 |
| `south` | 始终朝南 |
| `east` | 始终朝东 |
| `west` | 始终朝西 |
| `facing_horizontal` | 水平朝向，根据玩家面向方向放置 |
| `facing_all` | 全方向，根据玩家面向方向放置 |
| `clicking_horizontal` | 水平点击面，根据点击的面放置（仅水平方向） |
| `clicking_all` | 全方向点击面，根据点击的面放置 |
| `vertical` | 垂直方向，根据点击面或玩家视角决定 |

## 详细说明

### 固定方向
- `up`：方块始终朝上放置
- `down`：方块始终朝下放置
- `north`：方块始终朝北放置
- `south`：方块始终朝南放置
- `east`：方块始终朝东放置
- `west`：方块始终朝西放置

### `facing_horizontal`
根据玩家的面向方向决定方块的朝向，仅支持水平方向（东南西北），如箱子。

### `facing_all`
根据玩家的面向方向决定方块的朝向，支持所有六个方向，如活塞等。

### `clicking_horizontal`
根据玩家点击的方块面决定方块的朝向，仅支持水平方向。
如果点击的是上下面，则退化为 `facing_horizontal` 的行为，如告示牌。

### `clicking_all`
根据玩家点击的方块面决定方块的朝向，支持所有六个方向。

### `vertical`
根据点击的面或玩家视角决定垂直方向：
- 点击上下面时，朝向点击面
- 点击水平面时，根据玩家俯仰角决定朝上或朝下
