# JsonMore 文档目录

本文档提供了 JsonMore 模组的所有功能说明和使用指南。

## 方块类型

### [告示牌](方块类型/告示牌.md)
路径：`things/<命名空间>/block/`
- 支持站立式告示牌和墙挂式告示牌
- 可自定义木材类型

### [工匠箱](方块类型/工匠箱.md)
**需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**
路径：`things/<命名空间>/block/`
- 可自定义槽位数量和堆叠限制
- 支持物品过滤功能
- 可选择动态或固定槽位模式

### [流体储罐](方块类型/流体储罐.md)
**需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**
路径：`things/<命名空间>/block/`
- 可自定义容量的流体存储方块
- 支持透明渲染

## 物品类型

### [告示牌](物品类型/告示牌.md)
路径：`things/<命名空间>/item/`
- 对应告示牌方块的物品
- 支持站立式和墙挂式告示牌

### [铜罐](物品类型/铜罐.md)
**需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**
路径：`things/<命名空间>/item/`
- 可自定义容量的手持流体容器
- 用于存储和运输流体

## 匠魂附加

### [材料属性类型](匠魂附加/材料属性类型.md)
**需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**
路径：`things/<命名空间>/material_stat_type/`
- 定义新的材料属性类型
- 支持自定义工具属性
- 可设置修复能力和属性计算方式

## 说明

- `<命名空间>`：代表您的模组命名空间，例如 `mymod`
- 所有文档中的路径都应替换为实际的命名空间
- 标记为 **需要安装[匠魂3]** 的功能需要先安装 Tinkers' Construct 模组
