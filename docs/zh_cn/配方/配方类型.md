# 配方类型

JsonMore 注册了以下自定义配方类型，支持自定义消耗逻辑。

## 有序消耗配方 `jsonmore:shaped_consuming`

类似于原版有序配方，但使用 [自消耗原料](原料类型.md#自消耗原料) 的消耗逻辑。

**格式**：

```json
{
    "type": "jsonmore:shaped_consuming",
    "pattern": [
        "T#T",
        " W "
    ],
    "key": {
        "T": {
            "type": "jsonmore:tool_damaging",
            "ingredient": {
                "tag": "minecraft:pickaxes"
            },
            "damage": 5
        },
        "#": {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:iron_ingot"
            },
            "count": 3
        },
        "W": {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:water_bucket"
            },
            "count": 0
        }
    },
    "result": {
        "item": "minecraft:diamond",
        "count": 1
    }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 资源位置 | 必须为 `jsonmore:shaped_consuming` |
| `pattern` | 字符串数组 | 配方图案，每行一个字符串 |
| `key` | 对象 | 字符到原料的映射 |
| `result` | 对象 | 合成结果 |

`key` 中的原料可以是普通原料，也可以是 [自消耗原料](原料类型.md)。

---

## 无序消耗配方 `jsonmore:shapeless_consuming`

类似于原版无序配方，但使用 [自消耗原料](原料类型.md#自消耗原料) 的消耗逻辑。

**格式**：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "type": "jsonmore:tool_damaging",
            "ingredient": {
                "tag": "minecraft:pickaxes"
            },
            "damage": 1
        },
        {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:diamond"
            },
            "count": 9
        }
    ],
    "result": {
        "item": "minecraft:diamond_block",
        "count": 1
    }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 资源位置 | 必须为 `jsonmore:shapeless_consuming` |
| `ingredients` | 数组 | 原料列表 |
| `result` | 对象 | 合成结果 |

`ingredients` 中的原料可以是普通原料，也可以是 [自消耗原料](原料类型.md)。

## 使用 NBT 复制原料的示例

### 示例：附魔书转移特定附魔

将附魔书的第一个附魔转移到另一本书上：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "item": "minecraft:book"
        },
        {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:enchanted_book"
            },
            "mode": "MERGE_SOURCE_FIRST",
            "tags": [
                "StoredEnchantments[0]"
            ]
        }
    ],
    "result": {
        "item": "minecraft:enchanted_book",
        "count": 1
    }
}
```

**说明**：
- 第一个原料：普通书本（目标物品）
- 第二个原料：附魔书（源物品），只复制第一个附魔
- 结果：带有第一个附魔的附魔书
- 返还：附魔书变为普通书本（由 `remainder_override` 指定）

### 示例：保留物品名称和 Lore 的合成

将命名物品的名称和第一条 Lore 转移到新物品上：

```json
{
    "type": "jsonmore:shaped_consuming",
    "pattern": [
        "A",
        "B"
    ],
    "key": {
        "A": {
            "item": "minecraft:diamond_sword"
        },
        "B": {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:enchanted_book"
            },
            "mode": "MERGE_SOURCE_FIRST",
            "tags": [
                "display.Name",
                "display.Lore[0]"
            ]
        }
    },
    "result": {
        "item": "minecraft:diamond_sword",
        "count": 1
    }
}
```

**说明**：
- 将附魔书的自定义名称和第一条 Lore 复制到钻石剑上
- 使用 `MERGE_SOURCE_FIRST` 模式，冲突时使用源物品的值
- 适用于自定义命名装备的合成

### 示例：完全复制 NBT（替换模式）

完全复制源物品的 NBT 到目标物品：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "item": "minecraft:diamond_sword"
        },
        {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:golden_sword"
            },
            "mode": "REPLACE"
        }
    ],
    "result": {
        "item": "minecraft:diamond_sword",
        "count": 1
    }
}
```

**说明**：
- 使用 `REPLACE` 模式，完全清空钻石剑的原有 NBT
- 完全复制金剑的所有 NBT 数据（附魔、名称、耐久等）
- 适用于"升级"类合成，保留所有属性

## 物品交互配方 `jsonmore:item_application`

手持工具右键点击方块时触发。替换方块并消耗/损坏工具。

**格式**：

```json
{
    "type": "jsonmore:item_application",
    "block": {
        "item": "minecraft:stone"
    },
    "tool": {
        "type": "jsonmore:tool_damaging",
        "ingredient": {
            "tag": "minecraft:pickaxes"
        },
        "damage": 1
    },
    "result": {
        "item": "minecraft:cobblestone"
    },
    "sneaking": false
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `type` | 资源位置 | 是 | — | 必须为 `jsonmore:item_application` |
| `block` | [原料](原料类型.md) | 是 | — | 目标方块匹配器 |
| `tool` | [自消耗原料](原料类型.md#自消耗原料) | 是 | — | 手持物品匹配器，支持消耗逻辑 |
| `result` | 对象 | 是 | — | 替换后的物品结果 |
| `drop_container` | 布尔值 | 否 | `true` | 原方块处理方式：`true` 按破坏处理（容器内容物洒出），`false` 静默替换 |
| `keep_block_state` | 布尔值 | 否 | `false` | 是否保留原方块的 BlockState 属性 |
| `update_block` | 布尔值 | 否 | `true` | 是否触发方块更新（如红石更新、观察者检测） |
| `sneaking` | 布尔值 | 否 | *忽略* | 潜行要求 |
| `force_input` | 对象 | 否 | — | 按实际方块/状态匹配输入，绕过转物品匹配（无物品方块也能命中） |
| `force_output` | 对象 | 否 | — | 强制放置指定方块/方块状态，result 不必是该方块物品 |

**字段详解**：

- **block**：匹配目标方块的 [原料](原料类型.md)。支持 `nbt_copy` 等特殊原料，可在配方应用时处理方块 NBT。若被右键方块**没有对应物品**（如多数技术方块），则跳过此原料的物品匹配，此时必须搭配 `force_input` 才能命中。
- **tool**：手持物品的 [原料](原料类型.md)。支持 `tool_damaging`、`counted` 等自消耗原料，也可使用 `nbt_copy` 从工具复制 NBT 到结果。
- **result**：替换后的物品。若它是方块物品且未指定 `force_output`，则以该方块（默认状态）替换原位；若既非方块物品也无 `force_output`，移除原方块并掉落此物品。
- **drop_container**：原方块的处理方式。`true`（默认）按"破坏"处理——先不摘除方块实体，容器方块会按原版把内容物洒出（方块本体不走战利品掉落）；`false` 静默替换——先摘除旧方块实体再放置，**不会自动迁移旧方块数据**。要保留内容/数据，必须在 `block` 原料上用 `nbt_copy` 把方块数据写入 `result`，放置时会自动装载。
- **keep_block_state**：是否复制原方块的 BlockState 属性到新方块。复制时会自动匹配兼容属性，对于方向属性（如 `facing`），支持子集映射（如 6 方向 → 4 方向），并强制容器 `open=false`。`force_output` 中显式列出的属性会覆盖复制值。
- **update_block**：是否触发方块更新。`false` 时仅同步客户端显示，不触发邻近方块更新（红石、观察者等不会响应）。适用于"静默替换"场景；BE 数据装载与 `setPlacedBy` 仍会执行。
- **sneaking**：`true` 要求玩家潜行，`false` 要求玩家不潜行，不设置时忽略潜行状态。
- **force_input / force_output**：可选的状态规格对象，见下节。

### force_input / force_output 状态规格

两个字段均为可选对象，结构为 `{ "block": "...", "properties": { "属性名": "值" } }`，`block` 与 `properties` 都可省略：

- **force_input**：按被右键方块的**实际方块与属性**匹配（而非先转成物品）。只比较列出的属性，未列出的不要求；`block` 与属性需同时满足。方块有对应物品时，仍需先通过 `block` 原料的物品匹配（叠加）；无对应物品时只能靠它命中。
- **force_output**：指定放置的方块/方块状态，绕过"result 必须是可放置的方块物品、且只能放默认状态"的限制，因此可以输出**无物品方块**（如点燃的熔炉）与非默认状态。属性优先级：`force_output` 显式属性 > `keep_block_state` 复制值 > 默认值。
- 属性值统一按字符串书写，如 `"facing": "east"`、`"lit": "true"`。
- 放置成功后按原版"带 NBT 放置"流程处理：装载 `result` 携带的方块实体数据，并调用新方块的 `setPlacedBy`（JsonMore 告示牌等在此打开编辑界面）。`update_block=false` 时同样执行这两步，只是不广播方块更新。

> **注意**：配方触发需要手持物品位于 `jsonmore:item_application_tool` 物品标签中。工具包作者需要将可触发交互的工具添加到该标签。

### 示例：石镐右键石头变圆石

```json
{
    "type": "jsonmore:item_application",
    "block": {
        "item": "minecraft:stone"
    },
    "tool": {
        "type": "jsonmore:tool_damaging",
        "ingredient": {
            "tag": "minecraft:pickaxes"
        },
        "damage": 1
    },
    "result": {
        "item": "minecraft:cobblestone"
    },
    "sneaking": false
}
```

**说明**：
- 手持任何镐子右键石头
- 镐子消耗 1 点耐久
- 石头变为圆石
- 玩家不得潜行

### 示例：木桶升级为容器（保留物品）

```json
{
    "type": "jsonmore:item_application",
    "block": {
        "type": "jsonmore:nbt_copy",
        "ingredient": {
            "item": "minecraft:barrel"
        },
        "mode": "REPLACE"
    },
    "tool": {
        "type": "jsonmore:counted",
        "ingredient": {
            "item": "minecraft:paper"
        },
        "count": 0
    },
    "result": {
        "item": "testpack:test_container_plain"
    },
    "drop_container": false,
    "keep_block_state": true,
    "sneaking": true
}
```

**说明**：
- 潜行 + 纸右键木桶
- 木桶变为自定义容器，保留原木桶内的所有物品
- 保留方块状态属性
- 纸不消耗（`count: 0`）
- `nbt_copy` 将方块的 NBT 数据复制到结果物品

### 示例：放置非默认状态的方块（force_output）

```json
{
    "type": "jsonmore:item_application",
    "block": {
        "item": "minecraft:stone"
    },
    "tool": {
        "type": "jsonmore:counted",
        "ingredient": {
            "item": "minecraft:paper"
        },
        "count": 0
    },
    "result": {
        "item": "minecraft:furnace"
    },
    "force_output": {
        "block": "minecraft:furnace",
        "properties": {
            "facing": "east",
            "lit": "true"
        }
    }
}
```

**说明**：
- 纸右键石头
- 石头被替换为**点燃且朝东**的熔炉（非默认状态，普通放置无法得到）
- `result` 仍用于 JEI 展示与 NBT 载体，放置由 `force_output` 决定

### 交互标签 `jsonmore:item_application_tool`

物品标签，标记哪些物品可以触发 `item_application` 配方。只有标签中的物品右键方块时才会检查配方。

**示例**（数据包 `data/jsonmore/tags/items/item_application_tool.json`）：

```json
{
    "replace": false,
    "values": [
        "minecraft:iron_pickaxe",
        "minecraft:paper"
    ]
}
```

> **注意**：工具包作者必须在标签中添加自己的工具物品，否则配方不会被触发。

### JEI 显示

配方会显示在 JEI 的"物品交互"分类中，包含：
- 左侧：目标方块输入槽
- 左上：工具输入槽
- 右侧：结果输出槽
- 中间：放大显示的方块预览
- 右上角：潜行要求提示（白色加粗，如有设置）
