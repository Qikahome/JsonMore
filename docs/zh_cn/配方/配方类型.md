# 配方类型

JsonMore 注册了以下自定义配方类型，支持自定义消耗逻辑。

## 有序消耗配方 `jsonmore:shaped_consuming`

类似于原版有序配方，但使用 [自消耗原料](原料类型.md#自消耗原料) 的消耗逻辑。

**格式**：

```json
{
    "type": "jsonmore:shaped_consuming",
    "pattern": [
        "T#T",
        " W "
    ],
    "key": {
        "T": {
            "type": "jsonmore:tool_damaging",
            "ingredient": {
                "tag": "minecraft:pickaxes"
            },
            "damage": 5
        },
        "#": {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:iron_ingot"
            },
            "count": 3
        },
        "W": {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:water_bucket"
            },
            "count": 1,
            "remainder_override": {
                "id": "minecraft:water_bucket",
                "Count": 1
            }
        }
    },
    "result": {
        "item": "minecraft:diamond",
        "count": 1
    }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 资源位置 | 必须为 `jsonmore:shaped_consuming` |
| `pattern` | 字符串数组 | 配方图案，每行一个字符串 |
| `key` | 对象 | 字符到原料的映射 |
| `result` | 对象 | 合成结果 |

`key` 中的原料可以是普通原料，也可以是 [自消耗原料](原料类型.md)。

---

## 无序消耗配方 `jsonmore:shapeless_consuming`

类似于原版无序配方，但使用 [自消耗原料](原料类型.md#自消耗原料) 的消耗逻辑。

**格式**：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "type": "jsonmore:tool_damaging",
            "ingredient": {
                "tag": "minecraft:pickaxes"
            },
            "damage": 1
        },
        {
            "type": "jsonmore:counted",
            "ingredient": {
                "item": "minecraft:diamond"
            },
            "count": 9
        }
    ],
    "result": {
        "item": "minecraft:diamond_block",
        "count": 1
    }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 资源位置 | 必须为 `jsonmore:shapeless_consuming` |
| `ingredients` | 数组 | 原料列表 |
| `result` | 对象 | 合成结果 |

`ingredients` 中的原料可以是普通原料，也可以是 [自消耗原料](原料类型.md)。

## 使用 NBT 复制原料的示例

### 示例：附魔书转移特定附魔

将附魔书的第一个附魔转移到另一本书上：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "item": "minecraft:book"
        },
        {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:enchanted_book"
            },
            "mode": "MERGE_SOURCE_FIRST",
            "tags": [
                "StoredEnchantments[0]"
            ],
            "remainder_override": {
                "id": "minecraft:book",
                "Count": 1
            }
        }
    ],
    "result": {
        "item": "minecraft:enchanted_book",
        "count": 1
    }
}
```

**说明**：
- 第一个原料：普通书本（目标物品）
- 第二个原料：附魔书（源物品），只复制第一个附魔
- 结果：带有第一个附魔的附魔书
- 返还：附魔书变为普通书本

### 示例：保留物品名称和 Lore 的合成

将命名物品的名称和第一条 Lore 转移到新物品上：

```json
{
    "type": "jsonmore:shaped_consuming",
    "pattern": [
        "A",
        "B"
    ],
    "key": {
        "A": {
            "item": "minecraft:diamond_sword"
        },
        "B": {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:enchanted_book"
            },
            "mode": "MERGE_SOURCE_FIRST",
            "tags": [
                "display.Name",
                "display.Lore[0]"
            ]
        }
    },
    "result": {
        "item": "minecraft:diamond_sword",
        "count": 1
    }
}
```

**说明**：
- 将附魔书的自定义名称和第一条 Lore 复制到钻石剑上
- 使用 `MERGE_SOURCE_FIRST` 模式，冲突时使用源物品的值
- 适用于自定义命名装备的合成

### 示例：完全复制 NBT（替换模式）

完全复制源物品的 NBT 到目标物品：

```json
{
    "type": "jsonmore:shapeless_consuming",
    "ingredients": [
        {
            "item": "minecraft:diamond_sword"
        },
        {
            "type": "jsonmore:nbt_copy",
            "ingredient": {
                "item": "minecraft:golden_sword"
            },
            "mode": "REPLACE"
        }
    ],
    "result": {
        "item": "minecraft:diamond_sword",
        "count": 1
    }
}
```

**说明**：
- 使用 `REPLACE` 模式，完全清空钻石剑的原有 NBT
- 完全复制金剑的所有 NBT 数据（附魔、名称、耐久等）
- 适用于"升级"类合成，保留所有属性
