# 原料类型

JsonMore 注册了以下自定义原料类型，可用于配方和 `place_filter`（如 `FlexBarrelBlock` 的插入/提取过滤器）。

---

## 自消耗原料

自消耗原料是所有自定义消耗原料的基类。当配方使用自消耗原料时，合成后会调用其 `consume` 方法决定返还物品，而非原版的 `getCraftingRemainingItem`。

### 基类 `SelfConsumingIngredient`

**核心逻辑**：

```java
public static ItemStack consume(Ingredient ingredient, ItemStack stack) {
    if (stack.isEmpty())
        return stack;
    if (ingredient instanceof SelfConsumingIngredient selfConsumingIngredient)
        return selfConsumingIngredient.consume(stack);
    return vanillaConsume(stack); // 原版逻辑：返还 getCraftingRemainingItem
}
```

### 工具损坏原料 `jsonmore:tool_damaging`

匹配可损坏的工具，合成时消耗耐久度而非物品本身。

**格式**：

```json
{
    "type": "jsonmore:tool_damaging",
    "ingredient": {
        "tag": "minecraft:pickaxes"
    },
    "damage": 5
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 资源位置 | 是 | 必须为 `jsonmore:tool_damaging` |
| `ingredient` | 原料 | 是 | 内部原料，用于匹配物品 |
| `damage` | 整数 | 是 | 消耗的耐久度 |

**行为**：

- 匹配：物品必须是可损坏的工具，且剩余耐久度 ≥ `damage`
- 消耗：对工具造成 `damage` 点耐久伤害
- 返还：如果工具损坏，返还 `getCraftingRemainingItem`

**匠魂兼容**：如果安装了匠魂3，会正确处理强化耐久等 modifier。

### 计数原料 `jsonmore:counted`

匹配指定数量的物品，合成时消耗指定数量。

**格式**：

```json
{
    "type": "jsonmore:counted",
    "ingredient": {
        "item": "minecraft:diamond"
    },
    "count": 9
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 资源位置 | 是 | 必须为 `jsonmore:counted` |
| `ingredient` | 原料 | 是 | 内部原料，用于匹配物品 |
| `count` | 整数 | 是 | 需要的物品数量 |

**行为**：

- 匹配：物品栈数量 ≥ `count`
- 消耗：消耗 `count` 个物品
- 返还：`getCraftingRemainingItem` × `count`

### NBT 复制原料 `jsonmore:nbt_copy`

匹配物品，并在合成时将源物品的 NBT 数据复制到目标物品。支持多种复制模式和路径过滤。

**基础格式**：

```json
{
    "type": "jsonmore:nbt_copy",
    "ingredient": {
        "item": "minecraft:book"
    },
    "mode": "MERGE_SOURCE_FIRST"
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 资源位置 | 是 | 必须为 `jsonmore:nbt_copy` |
| `ingredient` | 原料 | 是 | 内部原料，用于匹配物品 |
| `mode` | 字符串 | 是 | NBT 复制模式（见下表） |
| `tags` | 字符串数组/字符串 | 否 | NBT 路径过滤，支持嵌套和数组索引 |

**复制模式**：

| 模式 | 说明 |
|------|------|
| `REPLACE` | 替换模式：清空目标物品的原有 NBT，完全复制源物品的 NBT |
| `MERGE_TARGET_FIRST` | 合并模式（目标优先）：将源物品的 NBT 合并到目标物品，冲突时使用目标物品的值 |
| `MERGE_SOURCE_FIRST` | 合并模式（源优先）：将源物品的 NBT 合并到目标物品，冲突时使用源物品的值 |

**路径格式**：

`tags` 字段支持以下路径格式：

- **简单标签名**：`"Enchantments"`, `"Damage"`
- **嵌套路径**：`"display.Name"`, `"display.Lore"`
- **数组索引**：`"display.Lore[0]"`, `"Enchantments[1]"`
- **混合使用**：`"Enchantments[0].id"`, `"Enchantments[0].lvl"`

**行为**：

- 匹配：匹配 `ingredient` 指定的物品
- 消耗：正常消耗物品，返还 `getCraftingRemainingItem`
- NBT 复制：根据 `mode` 和 `tags` 复制源物品的 NBT 到目标物品

**示例说明**：

上述带路径过滤的示例（如配合 `remainder_override` 包裹使用）会：
- 只复制 `display.Name`（附魔书的自定义名称）
- 只复制 `display.Lore` 的第一行（lore 的第一条）
- 只复制第一个附魔的 `id` 和 `lvl`
- 忽略其他所有 NBT 数据
- 合成后返还书本

> **注意**：NBT 复制原料通常用于附魔书、命名物品等需要保留或转移 NBT 数据的合成场景。

### 返还覆盖原料 `jsonmore:remainder_override`

包裹普通原料，强制覆盖其消耗后的返还物品。**内部原料不能是自消耗原料**（如 `jsonmore:counted`、`jsonmore:tool_damaging` 等）。

**格式**：

```json
{
    "type": "jsonmore:remainder_override",
    "ingredient": {
        "item": "minecraft:water_bucket"
    },
    "remainder_override": {
        "id": "minecraft:water_bucket",
        "Count": 1
    }
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 资源位置 | 是 | 必须为 `jsonmore:remainder_override` |
| `ingredient` | 原料 | 是 | 普通原料，不能是自消耗原料 |
| `remainder_override` | SNBT | 是 | 覆盖返还物品（物品栈的完整 SNBT 格式） |

**行为**：

- 先对物品栈执行原版消耗逻辑（消耗 1 个，返还原版容器物品）
- 无视原版返还结果，始终返回 `remainder_override` 中指定的物品

### 展示覆盖原料 `jsonmore:item_display_override`

包裹原料，对其 `getItems()` 返回的物品展示列表进行一系列操作。**不改变匹配和消耗逻辑**，仅影响 JEI/配方书等展示。

**格式**：

```json
{
    "type": "jsonmore:item_display_override",
    "ingredient": {
        "item": "minecraft:stick"
    },
    "ops": [
        { "op": "remove", "value": { "item": "minecraft:stick" } },
        { "op": "add", "value": { "id": "minecraft:diamond", "Count": 1 } },
        { "op": "add_all", "value": { "tag": "minecraft:planks" } },
        { "op": "modify_nbt", "value": { "Enchantments": [] }, "mode": "merge" },
        { "op": "modify_count", "operation": "multiply", "value": 2 }
    ]
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | 资源位置 | 是 | 必须为 `jsonmore:item_display_override` |
| `ingredient` | 原料 | 是 | 内部原料 |
| `ops` | 数组 | 是 | 操作列表，按顺序执行 |

**可用操作（op）**：

| 操作 | 说明 | `value` 类型 | 可选字段 |
|------|------|-------------|---------|
| `remove` | 从展示列表中移除匹配的物品栈 | 原料（Ingredient） | `filter` |
| `add_all` | 从另一个原料中获取所有物品栈并添加到展示列表 | 原料（Ingredient） | — |
| `add` | 添加一个指定的物品栈到展示列表 | 物品栈 SNBT | — |
| `modify_nbt` | 修改物品栈的 NBT（`mode` 可选 `merge`/`replace`） | CompoundTag | `filter`, `mode` |
| `modify_count` | 修改物品栈数量（`operation` 可选 `set`/`add`/`multiply`） | 整数 | `filter`, `operation` |

**`filter` 字段**：可选，类型为原料（Ingredient）。仅对匹配该过滤器的物品栈应用操作。

**行为**：

- 匹配和消耗完全委托给内部 `ingredient`
- 仅在 `getItems()` 返回时应用操作，影响展示（如 JEI 配方显示）
- 操作按 `ops` 数组顺序依次应用
- 每个操作作用于上一操作的最终结果列表

## 过滤器原料

以下原料类型仅用于匹配物品，不涉及消耗逻辑。

### `jsonmore:true`

始终匹配**所有**非空物品。  
在 JEI/配方书中会显示为一个名为"Anything"的木棍（仅作展示，不影响匹配逻辑）。

```json
{
  "type": "jsonmore:true"
}
```

### `jsonmore:not`

逻辑非（NOT）过滤器，匹配**不在**指定 `ingredient` 中的物品。  
在 JEI/配方书中会展示被排除物品的列表，并显示为"Anything except <原物品名>"。

```json
{
  "type": "jsonmore:not",
  "ingredient": {
    "tag": "minecraft:shulker_boxes"
  }
}
```

上述示例匹配所有**不是**潜影盒的物品。

### `jsonmore:keep_inventory_container`

匹配**可以保留物品栏的容器物品**（即 `FlexBarrelBlock` 中 `keep_inventory` 不为 `NEVER` 的容器）。支持两种模式：

| 模式 | 说明 |
|------|------|
| `may` | 匹配所有可以保留物品的容器（`keep_inventory` 为 `ALWAYS` 或 `SILK_TOUCH`） |
| `contains` | 匹配**当前包含物品**的保留物品栏容器（即容器内至少有一个非空物品槽） |

**示例**：

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "may"
}
```

匹配所有可以保留物品的容器（不论内部是否有物品）。

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "contains"
}
```

匹配所有**当前至少包含一个物品**的保留物品栏容器。

> 注意：`contains` 模式会检查物品的 `BlockEntityTag.Items` 列表，因此只有已经放置并存储了物品的容器物品才会被匹配。

## 组合使用

你可以将上述自定义原料与 Forge 的 `forge:compound`（OR）、`forge:intersection`（AND）等组合使用，实现复杂逻辑。

### 示例：匹配既不是潜影盒，也不是保留物品栏容器的物品

```json
{
  "type": "forge:intersection",
  "children": [
    {
      "type": "jsonmore:not",
      "ingredient": {
        "tag": "minecraft:shulker_boxes"
      }
    },
    {
      "type": "jsonmore:not",
      "ingredient": {
        "type": "jsonmore:keep_inventory_container",
        "mode": "may"
      }
    }
  ]
}
```

### 示例：匹配保留物品栏容器**或者**潜影盒

```json
{
  "type": "forge:compound",
  "children": [
    {
      "type": "jsonmore:keep_inventory_container",
      "mode": "may"
    },
    {
      "tag": "minecraft:shulker_boxes"
    }
  ]
}
```

## 在 `FlexBarrelBlock` 的 `place_filter` 中使用

`place_filter` 是一个 `ItemFilter`，可以直接使用上述任何 `Ingredient` JSON 对象。例如，只允许非保留物品栏容器的物品放入：

```json
{
  "place_filter": {
    "type": "jsonmore:not",
    "ingredient": {
      "type": "jsonmore:keep_inventory_container",
      "mode": "may"
    }
  }
}
```
