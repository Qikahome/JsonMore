# 容器（Container）

路径：`things/<命名空间>/block/`

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）方块类型ID，必须是 `"jsonmore:container"`
- **slots**（整数）容器槽位数量，具体范围与 GUI 屏幕类型有关，详见下文“GUI 屏幕类型”，默认 `27`
- **open_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）打开容器时播放的声音事件ID，默认木桶声音
- **close_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）关闭容器时播放的声音事件ID，默认木桶声音
- **can_waterlogged**（布尔值）是否可以被水淹没，默认 `false`
- **directions**（字符串）放置方向，可选值见[放置方向](../放置方向.md)，默认 `facing_horizontal`
- **keep_inventory**（字符串）保留物品模式，可选值见下表，默认 `never`

| 模式值 | 说明 |
|--------|------|
| `never` | 不保留物品，破坏后物品掉落 |
| `always` | 总是保留物品，类似潜影盒 |
| `silk_touch` | 仅精准采集时保留物品 |

- **anger_piglins**（布尔值）打开容器时是否激怒附近的猪灵，默认 `false`
- **blocked**（字符串）阻挡方向，当对应方向有实心方块时禁止打开，可选值见下表，默认 `never`

| 方向值 | 说明 |
|--------|------|
| `never` | 不检查阻挡 |
| `up` | 上方有实心方块时禁止打开 |
| `down` | 下方有实心方块时禁止打开 |
| `east` | 东方有实心方块时禁止打开 |
| `west` | 西方有实心方块时禁止打开 |
| `south` | 南方有实心方块时禁止打开 |
| `north` | 北方有实心方块时禁止打开 |
| `facing` | 方块面向方向有实心方块时禁止打开 |

- **insert_filters**（对象）按方向/面过滤**放入**物品，格式见下文，默认空
- **extract_filters**（对象）按方向/面过滤**取出**物品，格式同 `insert_filters`，默认空
- **place_filter**（Ingredient 或数组）物品放入通用限制，默认与 `keep_inventory` 联动（见下文）
- **screen**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）GUI 屏幕类型，可选值见下表，默认 `jsonmore:chest`
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项

## GUI 屏幕类型

| 屏幕 ID | 说明 | 槽位范围 | 备注 |
|---------|------|----------|------|
| `minecraft:chest` | 原版箱子界面 | 9 ~ 54，必须是9的倍数 | 无过滤器功能 |
| `jsonmore:chest` | 支持过滤器的箱子界面 | 9 ~ 54，必须是9的倍数 | 推荐使用 |
| `cyclopscore:scrolling` | CyclopsCore 滚动容器界面 | 建议 45 以上，且为9的倍数 | 需要安装 CyclopsCore |

`slots` 参数需在对应屏幕类型允许的范围内，否则可能无法正常显示。

## 保留物品机制

| 模式 | 说明 | 战利品表要求 |
|------|------|-------------|
| `never` | 不保留物品，破坏后物品掉落 | 正常配置即可 |
| `always` | 总是保留物品，类似潜影盒 | 不需要战利品表 |
| `silk_touch` | 仅精准采集时保留物品 | 需要特殊处理（见下文） |

### SILK_TOUCH 模式战利品表

使用 `silk_touch` 模式时，战利品表需要添加条件：**当有精准采集时不掉落物品**

```json
{
  "type": "minecraft:block",
  "pools": [
    {
      "rolls": 1,
      "entries": [
        {
          "type": "minecraft:item",
          "name": "命名空间:容器ID"
        }
      ],
      "conditions": [
        {
          "condition": "minecraft:survives_explosion"
        },
        {
          "condition": "minecraft:inverted",
          "term": {
            "condition": "minecraft:match_tool",
            "predicate": {
              "enchantments": [
                {
                  "enchantment": "minecraft:silk_touch",
                  "levels": { "min": 1 }
                }
              ]
            }
          }
        }
      ]
    }
  ]
}
```

## 物品放入/取出限制

### 通用限制（`place_filter`）

通过 `place_filter` 可设置放入物品的全局条件，使用标准 Ingredient 格式。支持自定义过滤器 `jsonmore:true`、`jsonmore:false`、`jsonmore:not`、`jsonmore:keep_inventory_container` 等。

默认行为：当 `keep_inventory` 不为 `never` 且未设置 `place_filter` 时，默认禁止放入 `jsonmore:cannot_place_in_keep_inventory` 标签中的物品以及任何保留物品栏容器（`keep_inventory_container`）。

### 按面限制（`insert_filters` / `extract_filters`）

可以为不同方向分别设置过滤器。键为面过滤器（可取 `any`、`all`、`same`、`opposite`、`up`、`down`、`north`、`south`、`east`、`west`），值为 Ingredient。

示例：
```json
{
  "insert_filters": {
    "up": { "tag": "minecraft:planks" },
    "opposite": { "type": "jsonmore:not", "ingredient": { "item": "minecraft:diamond" } }
  }
}
```

## 猪灵愤怒机制

- **打开时激怒**：设置 `anger_piglins: true`
- **破坏时激怒**：将方块添加到 `minecraft:guarded_by_piglins` 标签

## 示例

### 基础容器
```json
{
  "type": "jsonmore:container",
  "item": {}
}
```

### 潜影盒式容器
```json
{
  "type": "jsonmore:container",
  "slots": 27,
  "keep_inventory": "always",
  "item": {}
}
```

### 使用 CyclopsCore 滚动界面（81格）
```json
{
  "type": "jsonmore:container",
  "slots": 81,
  "screen": "cyclopscore:scrolling",
  "item": {}
}
```
