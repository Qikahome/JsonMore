# 容器（Container）

路径：`things/<命名空间>/block/`

格式如下：

 **（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）方块类型ID，必须是 `"jsonmore:container"`
- **slots**（整数）容器槽位数量，必须是9的倍数（9、18、27、36、45、54），默认 `27`
- **open_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）打开容器时播放的声音事件ID，默认木桶声音
- **close_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）关闭容器时播放的声音事件ID，默认木桶声音
- **can_waterlogged**（布尔值）是否可以被水淹没，默认 `false`
- **directions**（字符串）放置方向，可选值见[放置方向](../放置方向.md)，默认 `facing_horizontal`
- **keep_inventory**（字符串）保留物品模式，可选值见下表，默认 `never`

| 模式值 | 说明 |
|--------|------|
| `never` | 不保留物品，破坏后物品掉落 |
| `always` | 总是保留物品，类似潜影盒 |
| `silk_touch` | 仅精准采集时保留物品 |

- **anger_piglins**（布尔值）打开容器时是否激怒附近的猪灵，默认 `false`
- **blocked**（字符串）阻挡方向，当对应方向有实心方块时禁止打开，可选值见下表，默认 `never`

| 方向值 | 说明 |
|--------|------|
| `never` | 不检查阻挡 |
| `up` | 上方有实心方块时禁止打开 |
| `down` | 下方有实心方块时禁止打开 |
| `east` | 东方有实心方块时禁止打开 |
| `west` | 西方有实心方块时禁止打开 |
| `south` | 南方有实心方块时禁止打开 |
| `north` | 北方有实心方块时禁止打开 |
| `facing` | 方块面向方向有实心方块时禁止打开 |

- **insert_blocked_faces**（字符串数组）禁止从指定方向放入物品，可选值：`up`、`down`、`north`、`south`、`east`、`west`，默认空
- **extract_blocked_faces**（字符串数组）禁止从指定方向取出物品，可选值同上，默认空
- **place_filter**（字符串或对象）物品放入过滤器，格式见下文，默认空
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项

## 保留物品机制

| 模式 | 说明 | 战利品表要求 |
|------|------|-------------|
| `never` | 不保留物品，破坏后物品掉落 | 正常配置即可 |
| `always` | 总是保留物品，类似潜影盒 | 不需要战利品表 |
| `silk_touch` | 仅精准采集时保留物品 | 需要特殊处理（见下文） |

### SILK_TOUCH 模式战利品表

使用 `silk_touch` 模式时，战利品表需要添加条件：**当有精准采集时不掉落物品**

```json
{
  "type": "minecraft:block",
  "pools": [
    {
      "rolls": 1,
      "entries": [
        {
          "type": "minecraft:item",
          "name": "命名空间:容器ID"
        }
      ],
      "conditions": [
        {
          "condition": "minecraft:survives_explosion"
        },
        {
          "condition": "minecraft:inverted",
          "term": {
            "condition": "minecraft:match_tool",
            "predicate": {
              "enchantments": [
                {
                  "enchantment": "minecraft:silk_touch",
                  "levels": { "min": 1 }
                }
              ]
            }
          }
        }
      ]
    }
  ]
}
```

### 物品放入限制

通过 `place_filter` 属性可以自定义物品放入规则，使用标准的 Minecraft Ingredient 格式。

#### 基本格式

```json
{
  "place_filter": {
    "tag": "minecraft:shulker_boxes"
  }
}
```

只允许放入潜影盒。

#### NOT 过滤器

使用 `jsonmore:not` 类型实现黑名单：

```json
{
  "place_filter": {
    "type": "jsonmore:not",
    "ingredient": {
      "tag": "minecraft:shulker_boxes"
    }
  }
}
```

不允许放入潜影盒。

#### 组合过滤器

使用数组实现 OR 逻辑（任一匹配即可）：

```json
{
  "place_filter": [
    { "tag": "minecraft:planks" },
    { "tag": "minecraft:logs" }
  ]
}
```

使用 Forge 的 `forge:intersection` 实现 AND 逻辑：

```json
{
  "place_filter": {
    "type": "forge:intersection",
    "children": [
      { "tag": "minecraft:planks" },
      { "item": "minecraft:diamond" }
    ]
  }
}
```

#### 默认行为

当 `keep_inventory` 不为 `never` 且未设置 `place_filter` 时，默认过滤器为：

```json
[
  {
    "type": "jsonmore:not",
    "ingredient": { "tag": "jsonmore:cannot_place_in_keep_inventory" }
  },
  {
    "type": "jsonmore:not",
    "ingredient": { "type": "jsonmore:keep_inventory_container", "mode": "may" }
  }
]
```

即不允许放入：
- `jsonmore:cannot_place_in_keep_inventory` 标签中的物品（默认包含原版潜影盒）
- 任何 `keep_inventory` 不为 `never` 的容器物品

#### 保留物品栏容器过滤器

`jsonmore:keep_inventory_container` 类型支持两种模式：

| 模式 | 说明 |
|------|------|
| `may` | 匹配所有可以保留物品的容器（`keep_inventory` 不为 `never`） |
| `contains` | 匹配当前包含物品的保留物品栏容器 |

**示例** - 不允许放入已有物品的容器：
```json
{
  "place_filter": {
    "type": "jsonmore:not",
    "ingredient": {
      "type": "jsonmore:keep_inventory_container",
      "mode": "contains"
    }
  }
}
```

## 猪灵愤怒机制

- **打开时激怒**：设置 `anger_piglins: true`
- **破坏时激怒**：将方块添加到 `minecraft:guarded_by_piglins` 标签（需要在标签定义中配置）

## 示例

### 基础容器
```json
{
  "type": "jsonmore:container",
  "item": {}
}
```

创建一个默认的27格容器，使用木桶声音。

### 大型容器
```json
{
  "type": "jsonmore:container",
  "slots": 54,
  "open_sound": "minecraft:block.chest.open",
  "close_sound": "minecraft:block.chest.close",
  "item": {}
}
```

创建一个54格（双倍大箱子大小）的容器，使用箱子声音。

### 可含水容器
```json
{
  "type": "jsonmore:container",
  "slots": 9,
  "can_waterlogged": true,
  "directions": "facing_all",
  "item": {}
}
```

创建一个9格的小型容器，可以放置在水中，支持全方向放置。

### 潜影盒式容器
```json
{
  "type": "jsonmore:container",
  "slots": 27,
  "keep_inventory": "always",
  "item": {}
}
```

创建一个27格的容器，破坏后保留物品，类似潜影盒。

### 猪灵愤怒容器
```json
{
  "type": "jsonmore:container",
  "slots": 27,
  "anger_piglins": true,
  "item": {}
}
```

创建一个27格的容器，打开时会激怒附近的猪灵，类似箱子或木桶。

### 阻挡检测容器
```json
{
  "type": "jsonmore:container",
  "slots": 27,
  "blocked": "facing",
  "item": {}
}
```

创建一个27格的容器，当方块面向方向有实心方块时无法打开。

### 面控制容器
```json
{
  "type": "jsonmore:container",
  "insert_blocked_faces": ["up", "down"],
  "extract_blocked_faces": ["north"],
  "item": {}
}
```

创建一个禁止从上下方向放入物品、禁止从北方取出物品的容器。
