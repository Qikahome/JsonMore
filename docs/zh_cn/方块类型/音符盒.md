# 音符盒（Note Block）

路径：`things/<命名空间>/block/`

*需要安装 [Anvil MusBox](https://github.com/Qikahome/Anvil_MusBox) 前置模组*

格式如下：

 **（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）方块类型ID，必须是 `"jsonmore:noteblock"`
- **instrument_block_tag**（String）乐器对应的方块标签，用于判断下方方块是否匹配该乐器
- **instrument_name**（String）乐器名称的翻译键，如 `"block.minecraft.amethyst_block"`
- **sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）播放的声音事件ID，和/playsound使用的格式相同
- **volume**（Float）音量，默认 `1.0`
- **not_solid**（Boolean）是否非实体方块，默认 `false`
- **has_collision**（Boolean）是否有碰撞箱，默认 `true`
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项

## 示例

```json
{
  "type": "jsonmore:noteblock",
  "instrument_block_tag": "crystal_sound_blocks",
  "instrument_name": "block.minecraft.amethyst_block",
  "sound": "block.amethyst_block.chime",
  "volume": 100,
  "not_solid": true,
  "has_collision": false
}
```

此示例创建一个紫水晶风格的音符方块：放置在标签 `crystal_sound_blocks` 内的方块上时作为乐器，播放紫水晶钟声，音量设为 100，且无碰撞箱。
