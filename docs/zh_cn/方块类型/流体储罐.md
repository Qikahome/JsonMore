# 流体储罐

 **需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**

路径：`things/<命名空间>/block/`

格式如下：

 **（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）方块类型ID，必须是`"jsonmore:fluid_tank"`
- **capacity**（整数）储罐容量。默认为`4000`。
- **item**（字典）
- - **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）物品类型ID，必须是`"jsonmore:fluid_tank"`
  - 其他在[物品定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Items.md)中支持的项
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项
