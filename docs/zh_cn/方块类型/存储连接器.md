# 存储连接器（Storage Connector）

路径：`things/<命名空间>/block/`

**（Object）** 根对象。
- **type**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）方块类型ID，必须是 `"jsonmore:storage_connector"`
- **radius**（整数）扫描半径，以连接器为中心的立方体范围，默认 `4`
- **max_connectors**（整数）最大可连接容器数量，达到后停止吸收并阻断后续扫描，默认 `-1`（无限制）
- **max_capacity**（整数）最大总容量（槽位数），达到后停止吸收并阻断后续扫描，默认 `-1`（无限制）
- **connectable**（字符串）可连接方块标签ID，不包含 `#` 前缀。例如 `"minecraft:wool"` 对应标签 `#minecraft:wool`。**必填**
- **screen**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID) 或 对象）GUI 屏幕类型，支持区间映射格式（见[容器文档](容器.md#区间映射格式)），默认 `autosizedgui:auto`
- **assemble_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）组装时播放的音效，默认 `minecraft:block.beacon.activate`
- **disassemble_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）拆解时播放的音效，默认 `minecraft:block.beacon.deactivate`
- **open_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）打开 GUI 时播放的音效，默认 `minecraft:block.barrel.open`
- **close_sound**（[资源位置](https://zh.minecraft.wiki/w/%E5%91%BD%E5%90%8D%E7%A9%BA%E9%97%B4ID)）关闭 GUI 时播放的音效，默认 `minecraft:block.barrel.close`

- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项

## 概述

存储连接器是一种中央控制器方块，可以扫描并连接周围（立方体范围内）的容器，将所有连接的容器统一管理。它特别适用于需要集中管理大量容器物品的场景。

### 工作原理

1. **组装**：在连接器上潜行+空手右键，BFS 搜索相邻的 `connectable` 方块路径，找到的所有可连接容器（仅 `jsonmore:container` 类型）会被组装到连接器中。
2. **物品吸收**：组装时，连接器会吸收所有容器的物品到自身，并在 GUI 中统一管理和显示。
3. **增量添加**：已经组装过的连接器再次潜行+右键，会保留现有连接并增量扫描范围内的新容器，不会重复添加已连接的容器。
4. **界面**：右键打开连接器的 GUI，显示所有物品。
5. **拆解**：破坏连接器方块会触发拆解，将所有容器还原并分发物品回各自容器。
6. **方块状态**：组装后连接器方块显示 `connected=true`。

### 容器行为

- 被连接的容器方块**不会被移除**，外观保持不变，但方块状态会显示 `connected=true`
- 被连接后，容器无法独立打开或交互，所有操作通过连接器 GUI 完成
- 破坏被连接的容器/连接器**会被拦截**：方块不会消失，而是先触发整个连接体的拆解（前提是能找到控制器），再保留方块
- 管线和自动化设备可以通过连接器的 capabilities 直接交互

## 示例

### 基础存储连接器
```json
{
  "type": "jsonmore:storage_connector",
  "radius": 4,
  "connectable": "minecraft:wool",
  "screen": "autosizedgui:auto",
  "item": {}
}
```

### 大范围存储连接器
```json
{
  "type": "jsonmore:storage_connector",
  "radius": 8,
  "connectable": "extended_storage:barrels",
  "screen": "cyclopscore:scrolling",
  "item": {}
}
```
