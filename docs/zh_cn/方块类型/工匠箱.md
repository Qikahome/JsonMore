# 工匠箱

 **需要安装[匠魂3](https://github.com/SlimeKnights/TinkersConstruct)**

路径：`things/<domain>/block/`

格式如下：

 **（Object)** 根对象。
- **type**（[资源位置](https://slimeknights.github.io/docs/json/resource-location/#format)）方块类型ID，必须是`"jsonmore:tinker_chest"`
- **drop_items**（布尔）可选，默认为`true`，代表该工匠箱是否挖掘时保留内容物。*（未经测试）*
- **translation_key**（字符串）可选，默认为该方块的翻译键，打开GUI时左上角的默认名称。*（未经测试）*
- **slot_mode**（字符串）可选，默认为`"scaling"`，可选的值：`"scaling"`：大小动态变化（如部件箱） `"fixed"`：固定大小（如工匠箱）。*（未经测试）*
- **max_slots**（整数）可选，默认为`27`，代表工匠箱的容量/最大容量。*（未经测试）*
- **slot_stack_limit**（整数）可选，默认为`64`，代表工匠箱的单槽最大堆叠数，超过64的值未定义。*（未经测试）*
- **allow_duplicate_item**（布尔）仅在**slot_mode**为`"scaling"`时候可选，默认为`true`，代表工匠箱是否接受重复的物品。*（未经测试）*
- **filters**（列表\[资源位置\]）仅在**slot_mode**为`"scaling"`时候可选，代表只有同时拥有这些标签的物品可以放入。*（未经测试）*
- - （资源位置）一个物品标签
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项
