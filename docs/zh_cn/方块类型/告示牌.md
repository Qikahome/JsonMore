# 告示牌

路径：`things/<命名空间>/block/`

格式如下：

 **（Object）** 根对象。
- **type**（[资源位置](https://slimeknights.github.io/docs/json/resource-location/#format)）方块类型ID，必须是`"jsonmore:standing_sign"`或`"jsonmore:wall_sign"`
- **wood_type**（木头类型）可选，默认为`"oak"`
- **item**（字典）不填，单独注册[告示牌物品](../%E7%89%A9%E5%93%81%E7%B1%BB%E5%9E%8B/%E5%91%8A%E7%A4%BA%E7%89%8C.md)
- 其他在[方块定义](https://github.com/gigaherz/JsonThings/blob/1.20.1/documentation/formats/Blocks.md)中支持的项
