# 内置数据包（Built-in Datapack）

允许将数据包直接打包在模组 JAR 文件中，使其出现在"数据包"选择界面中，玩家可以像其他数据包一样启用或禁用它们。

路径：`things/<命名空间>/built_in_datapack/`

**（Object）** 根对象。
- **default_enable**（布尔值，可选）数据包是否默认启用，默认为 `false`
- **display_name**（[文本组件](https://zh.minecraft.wiki/w/%E5%8E%9F%E5%A7%8BJSON%E6%96%87%E6%9C%AC%E6%A0%BC%E5%BC%8F)，可选）数据包在界面中显示的名称。未指定时，将使用可翻译文本键 `pack.<命名空间>.<路径>`

数据包文件应放在模组 JAR 内的 `datapacks/<路径>/` 目录下，其中 `<路径>` 对应注册名的路径部分。

## 示例

```json
{
  "default_enable": true,
  "display_name": {
    "text": "Example Mod Tweaks"
  }
}
```

该示例注册了一个位于模组 JAR 内 `datapacks/example_tweaks/` 路径下的数据包，默认启用，显示名为"Example Mod Tweaks"。
