# 自定义过滤器

JsonMore 注册了以下自定义 Ingredient 类型，可用于配方和 `place_filter`（如 `FlexBarrelBlock` 的插入/提取过滤器）。

## `jsonmore:true`

始终匹配**所有**非空物品。  
在 JEI/配方书中会显示为一个名为“Anything”的木棍（仅作展示，不影响匹配逻辑）。

```json
{
  "type": "jsonmore:true"
}
```

## `jsonmore:false`

始终不匹配任何物品（等价于空 Ingredient）。  
在 JEI/配方书中不会显示任何物品。

```json
{
  "type": "jsonmore:false"
}
```

## `jsonmore:not`

逻辑非（NOT）过滤器，匹配**不在**指定 `ingredient` 中的物品。  
在 JEI/配方书中会展示被排除物品的列表，并显示为“Anything except <原物品名>”。

```json
{
  "type": "jsonmore:not",
  "ingredient": {
    "tag": "minecraft:shulker_boxes"
  }
}
```

上述示例匹配所有**不是**潜影盒的物品。

## `jsonmore:keep_inventory_container`

匹配**可以保留物品栏的容器物品**（即 `FlexBarrelBlock` 中 `keep_inventory` 不为 `NEVER` 的容器）。支持两种模式：

| 模式 | 说明 |
|------|------|
| `may` | 匹配所有可以保留物品的容器（`keep_inventory` 为 `ALWAYS` 或 `SILK_TOUCH`） |
| `contains` | 匹配**当前包含物品**的保留物品栏容器（即容器内至少有一个非空物品槽） |

**示例**：

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "may"
}
```

匹配所有可以保留物品的容器（不论内部是否有物品）。

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "contains"
}
```

匹配所有**当前至少包含一个物品**的保留物品栏容器。

> 注意：`contains` 模式会检查物品的 `BlockEntityTag.Items` 列表，因此只有已经放置并存储了物品的容器物品才会被匹配。

## 组合使用（与 Forge 内置过滤器）

你可以将上述自定义过滤器与 Forge 的 `forge:compound`（OR）、`forge:intersection`（AND）等组合使用，实现复杂逻辑。

### 示例：匹配既不是潜影盒，也不是保留物品栏容器的物品

```json
{
  "type": "forge:intersection",
  "children": [
    {
      "type": "jsonmore:not",
      "ingredient": {
        "tag": "minecraft:shulker_boxes"
      }
    },
    {
      "type": "jsonmore:not",
      "ingredient": {
        "type": "jsonmore:keep_inventory_container",
        "mode": "may"
      }
    }
  ]
}
```

### 示例：匹配保留物品栏容器**或者**潜影盒

```json
{
  "type": "forge:compound",
  "children": [
    {
      "type": "jsonmore:keep_inventory_container",
      "mode": "may"
    },
    {
      "tag": "minecraft:shulker_boxes"
    }
  ]
}
```

## 在 `FlexBarrelBlock` 的 `place_filter` 中使用

`place_filter` 是一个 `ItemFilter`，可以直接使用上述任何 `Ingredient` JSON 对象。例如，只允许非保留物品栏容器的物品放入：

```json
{
  "place_filter": {
    "type": "jsonmore:not",
    "ingredient": {
      "type": "jsonmore:keep_inventory_container",
      "mode": "may"
    }
  }
}
```
