# 自定义过滤器

JsonMore 注册了以下自定义 Ingredient 类型，可用于配方和 `place_filter`。

## jsonmore:true

始终匹配所有物品。

```json
{
  "type": "jsonmore:true"
}
```

## jsonmore:false

始终不匹配任何物品。

```json
{
  "type": "jsonmore:false"
}
```

## jsonmore:not

NOT 逻辑过滤器，匹配不在指定 Ingredient 中的物品。

```json
{
  "type": "jsonmore:not",
  "ingredient": {
    "tag": "minecraft:shulker_boxes"
  }
}
```

匹配所有不是潜影盒的物品。

## jsonmore:keep_inventory_container

匹配保留物品栏容器物品。

| 模式 | 说明 |
|------|------|
| `may` | 匹配所有可以保留物品的容器（`keep_inventory` 不为 `never`） |
| `contains` | 匹配当前包含物品的保留物品栏容器 |

**示例**：

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "may"
}
```

匹配所有可以保留物品的容器。

```json
{
  "type": "jsonmore:keep_inventory_container",
  "mode": "contains"
}
```

匹配所有当前包含物品的保留物品栏容器。

## 组合使用

配合 Forge 内置的 `forge:intersection`（AND）和数组（OR）可以实现复杂逻辑：

```json
{
  "type": "forge:intersection",
  "children": [
    { "type": "jsonmore:not", "ingredient": { "tag": "minecraft:shulker_boxes" } },
    { "type": "jsonmore:not", "ingredient": { "type": "jsonmore:keep_inventory_container", "mode": "may" } }
  ]
}
```

匹配既不是潜影盒也不是保留物品栏容器的物品。
